# Checklist relecture — rédaction GN

À appliquer **dans l'ordre** après chaque brouillon (skill `SKILL.md`, passes 4 à 7).

## Contenu

- [ ] Chaque phrase dit **une chose précise** (sinon couper ou fusionner).
- [ ] Aucune information **inventée** : tout vient des bullets, des sources lues ou des directives.
- [ ] Chaque paragraphe utile contient au moins un fait **jouable** (relation, contrainte, lieu, document, délai, risque).
- [ ] Paragraphes « ambiance seule » supprimés.
- [ ] Acteurs nommés : qui fait quoi, avec quel instrument (contrat, registre, route…).
- [ ] Sections biographie : ≥ 3 phrases chacune ; ≥ 2 ancrages (date, lieu, nom, chiffre, document) par section.

## Anti-charabia (passe 4)

- [ ] Aucune section biographie ≤ 2 phrases.
- [ ] Pas de mot en gras qui porte seul le sens.
- [ ] Pas de métaphore, jeu de mots, image poétique, sens caché.
- [ ] Pas de mot abstrait seul (*marge*, *levier*, *angle*, *ombre*, *voix*, *fil*) sans acteur et action.
- [ ] Pas de formes indirectes (*est déposé*, *laissée en veille*, *faire en sorte que…*) dans la voix perso.
- [ ] Peur / rêve / valeurs : faits concrets, pas énigmes.

## Style

- [ ] Pas de métalangage JdR : pas de « selon ce que la table… », « à la table », « accord table », « autoplay ».
- [ ] Pas de « ligne de… » / « tenir la ligne » au sens fil d'intrigue orga.
- [ ] Pas de dramatisation artificielle.
- [ ] Pas de verbes flous sans complément — préciser qui subit quoi.
- [ ] Pas d'accumulation d'adjectifs si un fait suffit.
- [ ] Pas de formules d'auteur (*le lecteur comprendra*, *peu de gens savent*).
- [ ] Une idée par phrase ; pas de point-virgule pour trois idées ; pas de subordonnées empilées.
- [ ] Paragraphes : **2 à 5 phrases**, un sujet par paragraphe.
- [ ] Lecture à voix haute : brief à un autre PJ — si prétentieux ou faux → simplifier.

## « Tu » (si 2e personne)

- [ ] Pas d'enchaînement *Tu sais… Tu comprends… Tu réalises…*
- [ ] Alternance : parfois commencer par le lieu, le contexte, un nom propre.

## Densité (rôle joueur — passe 6)

- [ ] Biographie ≥ 40 lignes (≥ 25 si rôle secondaire).
- [ ] ≥ 5 sections biographie à titres explicites (pas chapitres vides I–V).
- [ ] ≥ 3 objectifs prioritaires avec verbe + résultat.
- [ ] `# Connaissances` : un `##` par contact **hors groupe** ou sujet ; pas de fiche sur les coéquipiers.

## Sens explicite (passe 7 — finale)

- [ ] Relu **document entier** phrase par phrase **et chapitre par chapitre** après passes 4–6.
- [ ] Aucune image détournée (*secondes*, *portes*, *brûler une source*, *cesse de respirer*, *mise sur*, *terrain de jeu*).
- [ ] Chaque phrase : qui + verbe concret + objet/lieu/document.
- [ ] Pas de jargon orga ou anglais dans le texte joueur (*cover story*, *PJ*, *double rôle*).
- [ ] Test phrase « concrètement tu fais quoi ? » : la phrase tient sans explication du rédacteur.
- [ ] Test chapitre « à quoi ça sert en jeu ? » : chaque section biographie et bloc Connaissances se comprend sans lire une autre fiche.
- [ ] Aucune information injouable : pas de liste de noms ou code pièce sans cadre, rôle de chaque acteur et geste possible.
- [ ] Chapitres avec fil clair (chronologie ou chantier) ; paragraphes 2–5 phrases ; Connaissances au même niveau de détail que la biographie.

## Markdown selon livrable

**Joueur** (backs, codex joueur, fiches, gazette, contrats remis…) :
- [ ] Pas de gras décoratif.
- [ ] Pas de mention `*(règlement — orga)*` (ni variante) dans les fiches rôle.
- [ ] Structure par titres, listes, tableaux ; libellés `Intitulé : détail` sans `**`.

**Orga** (`Intrigues/`, `Afaire.md`, notes MJ) :
- [ ] Gras uniquement sur intitulé immédiat avant `:` en tête de puce ou de ligne.
- [ ] Pas de gras dans le corps de phrase.

## Cohérence dépôt

- [ ] Noms canon identiques aux sources.
- [ ] Secrets réservés à un PJ ou au MJ absents d'un back groupe partagé (si applicable).
- [ ] Pas de copier-coller d'un doc technique entier.

## Verdict

- [ ] Le style est **discret** : l'attention va au contenu, pas à la formulation.
- [ ] Un joueur peut déduire au moins **trois actions possibles** après lecture.
