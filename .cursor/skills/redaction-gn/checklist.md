# Checklist relecture — rédaction GN

À appliquer **dans l'ordre** après chaque brouillon (Style.md §9).

## Contenu

- [ ] Chaque phrase dit **une chose précise** (sinon couper ou fusionner).
- [ ] Aucune information **inventée** : tout vient des bullets, des sources lues ou des directives.
- [ ] Chaque paragraphe utile contient au moins un fait **jouable** (relation, contrainte, lieu, document, délai, risque).
- [ ] Paragraphes « ambiance seule » supprimés (§7).
- [ ] Acteurs nommés : qui fait quoi, avec quel instrument (contrat, registre, route…).

## Style

- [ ] Pas de métaphore, image poétique, dramatisation artificielle (§3).
- [ ] Pas de verbes flous sans complément (*les taux suivent*, *ça trace*) — préciser qui subit quoi.
- [ ] Pas d'accumulation d'adjectifs (tragique, crucial, inestimable…) si un fait suffit (§8).
- [ ] Pas de formules d'auteur (*le lecteur comprendra*, *peu de gens savent*).
- [ ] Une idée par phrase ; pas de point-virgule pour trois idées ; pas de subordonnées empilées (§4).
- [ ] Paragraphes : **2 à 5 phrases**, un sujet par paragraphe (§5).
- [ ] Lecture à voix haute : tout ce qui sonne **prétentieux ou faux** → simplifier.

## « Tu » (si 2e personne)

- [ ] Pas de enchaînement *Tu sais… Tu comprends… Tu réalises…* (§6).
- [ ] Alternance : parfois commencer par le lieu, le contexte, un nom propre.

## Markdown selon livrable

**Joueur** (backs, codex joueur, fiches, gazette, contrats remis…) :
- [ ] Pas de gras décoratif (Style.md §11).
- [ ] Structure par titres, listes, tableaux ; libellés en `Intitulé : détail` sans `**`.

**Orga** (`Intrigues/`, `Afaire.md`, notes MJ) :
- [ ] Gras uniquement sur intitulé immédiat avant `:` en tête de puce ou de ligne.
- [ ] Pas de gras dans le corps de phrase.

## Cohérence dépôt

- [ ] Noms canon identiques aux sources.
- [ ] Secrets réservés à un PJ ou au MJ **absents** d'un back groupe partagé (si applicable).
- [ ] Pas de copier-coller d'un doc technique entier.

## Verdict

- [ ] Le style est **discret** : l'attention va au contenu, pas à la formulation (§10).
