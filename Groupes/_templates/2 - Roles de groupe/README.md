# Template — Rôles joueurs (individuels)

Une fiche par joueur, **après** le Back_groupe collectif et **alignée** sur `Intrigues/Intrigue_[Groupe].md`.

- **Gabarit** : `template_GROUPE_NomDuPersonnage_role.md`
- **Relations et contacts** : uniquement sous `# Connaissances` — contacts **hors groupe** et pièces ; pas de `##` sur les coéquipiers.
- **Nom de fichier livrable** : `{Groupe}_{NomDuPersonnage}_{RoleDansLeGroupe}.md` (ex. `Palyr_Lysa_Morwyn_Tresoriere.md`, `UBI_Melian_Torv_Conseiller_spirituel.md`)
- **Dossier type** : `Groupes/[Groupe]/2 - Roles des Joueurs/`

Voir la méthode complète : `Groupes/_templates/README.md`.
