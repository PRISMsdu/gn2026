# Template de Prompt - Génération d'Intrigue

## Instructions d'utilisation

1. **Copier ce template** dans le répertoire `./prompts/` avec le nom `prompt_Intrigue_[NOM_DU_GROUPE].md`
2. **Compléter les sections** avec les informations spécifiques au groupe
3. **Exécuter le prompt** en utilisant l'IA pour générer l'intrigue
4. **Sauvegarder le prompt utilisé** pour référence future

Je veux créer une intrigue pour le groupe **Il-irion** dans l'univers de Krondaar. Cette intrigue doit être immersive, dramatique et offrir des enjeux clairs pour les joueurs.

## Instructions de génération

Génère une intrigue complète en utilisant le template `template_intrigue.md` avec les sections suivantes :

1. **Informations Générales** : Nom accrocheur, type d'intrigue, groupe concerné
2. **Contexte et Situation** : Situation initiale, contexte historique, enjeux
3. **Objectifs** : Objectif principal et secondaires clairs
4. **Acteurs et Parties Prenantes** : Tableau avec relations détaillées
5. **Ressources et Moyens** : Financiers, matériels, humains, informationnels
6. **Plans et Stratégies** : Plan principal avec étapes clés
7. **Composition du Groupe** : Rôles nécessaires basés sur l'intrigue
8. **Secrets et Informations Sensibles** : Secrets, informations, objets, conflits, actions passées

## Style et Format

- **Ton** : Dramatique et immersif
- **Format** : Markdown strictement conforme au template
- **Longueur** : 3-4 pages A4
- **Détails** : Concrets et utilisables en jeu
- **Cohérence** : Avec l'univers de Krondaar et les autres groupes
