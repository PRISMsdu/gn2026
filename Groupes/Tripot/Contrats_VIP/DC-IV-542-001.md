# DC-IV-542-001 -- Routes forcees par Il-Irion pour interets prives

Document prive. Exemplaire unique.

DOSSIER CLANDESTIN  
No DC-IV-542-001

Periode : 542-543.  
Code payeur : II.  
Cite executante : Il-Irion.  
Reglements rattaches : 15.  
Somme consolidee : 30'000 couronnes.  
Classement : IV.

Objet du dossier : operations d'Il-Irion contre capitaines, timoniers, armateurs et equipages concurrents.

Faits couverts : enlevement d'un timonier, chantage sur capitaines, passages non declares, malles fermees, faux retours de cale et menaces sur equipages.

## Engagements

Le porteur du code II agit comme payeur. Il remet les sommes indiquees a Il-Irion pour le compte d'interets prives nommes dans les reglements : maisons d'armement, capitaines endettes, marchands proteges, pirates ou guildes de port.
Il-Irion recoit ces sommes pour organiser, gerer et faire executer les faits couverts. Il-Irion choisit les agents, paie les relais, contraint les capitaines utiles et fait disparaitre les personnes ou marchandises mentionnees.
Chaque reglement constate une action deja demandee a Il-Irion ou executee par Il-Irion : pression sur un capitaine, enlevement d'un marin, fausse entree de cale, transport d'une malle fermee, immobilisation d'un equipage ou livraison d'un nom a un groupe violent.
Les personnes designees dans les reglements peuvent etre retenues, menacees, deplacees, forcees a signer ou tuees si l'action l'exige. Les navires vises peuvent etre retardes, detournes, charges sous faux motif ou prives d'une partie de leur equipage.
Le porteur du code II reconnait que les quinze versements forment un seul dossier contre Il-Irion : chaque ligne rattache une somme, un tiers servi et une action precise a l'organisation ilirionienne.
