# Groupe — Voleurs Corbeaux de Minuit

## Structure des répertoires

### `1 - Back de groupe`
- `Back_groupe_Corbeaux_Minuit.md` — Fiche groupe (méthode template)
- `Historique_Corbeaux_Minuit.md` — Historique synthétique
- `interactions_Corbeaux_vers_autres_groupes.csv` — Interactions vers les autres groupes
- `RAF-voleur.md` — Checklist orga (contacts, lettre Edorian, mécaniques)

### `2 - Backs de persos`
Fiches **orga** (`perso_Corbeaux_*-orga.md`) — base pour générer ensuite les rôles joueurs.

### `3 - Roles des joueurs`
Rôles finaux distribués aux joueurs — *à produire à partir des backs orga* (brouillon narratif groupé conservé sous forme de fichier source).

## Workflow (cf. `Groupes/_templates/README.md`)
1. Intrigue (tout-en-un orga) → 2. Histoire joueurs si besoin → 3. Backs perso orga → 4. Rôles joueurs
