### Système de Numérotation
- **Format** : `UBI-[N°]` (ex: UBI-001, UBI-002, etc.)
- **Séquence** : Numérotation continue depuis 496
- **Préfixes spéciaux** : 
  - `UBI-SEC-[N°]` pour les documents ultra-secrets
  - `UBI-TEMP-[N°]` pour les documents temporaires

## Classification par Criticité

### 🔴 Critique
- **Définition** : Documents pouvant causer la chute de gouvernements, révélations de crimes majeurs, génocides
- **Accès** : Directeur uniquement + 1 garde de confiance
- **Exemples** : Plans de coups d'État, preuves de génocide, chantage sur dirigeants suprêmes

### 🟠 Très Sensible
- **Définition** : Scandales politiques majeurs, malversations importantes, chantage sur nobles
- **Accès** : Conseil de direction + archiviste en chef
- **Exemples** : Malversations bancaires, scandales sexuels de nobles, accords secrets entre cités

### 🟡 Sensible
- **Définition** : Secrets commerciaux, affaires privées compromettantes, correspondances diplomatiques
- **Accès** : Personnel autorisé + archivistes
- **Exemples** : Contrats commerciaux sensibles, correspondances diplomatiques, dettes personnelles importantes

### 🟢 Standard
- **Définition** : Contrats normaux, correspondances publiques, documents administratifs
- **Accès** : Personnel bancaire standard
- **Exemples** : Prêts standards, contrats de mariage publics, testaments normaux

## Zones de Coffres par Criticité

### 🔴 Critique (Coffres 1-25)
- **Sécurité** : Triple verrouillage, gardes 24h/24
- **Accès** : Directeur + 1 clé de secours
- **Exemples** : Constitutions, plans de coups d'État, preuves de crimes majeurs

### 🟠 Très Sensible (Coffres 26-50)
- **Sécurité** : Double verrouillage, gardes de jour
- **Accès** : Conseil de direction + archiviste en chef
- **Exemples** : Malversations, scandales politiques, accords secrets

### 🟡 Sensible (Coffres 51-75)
- **Sécurité** : Verrouillage standard, surveillance
- **Accès** : Personnel autorisé + archivistes
- **Exemples** : Contrats commerciaux, correspondances diplomatiques

### 🟢 Standard (Coffres 76-100)
- **Sécurité** : Verrouillage basique
- **Accès** : Personnel bancaire standard
- **Exemples** : Prêts standards, documents administratifs

## Types de Documents et Templates

### 1. Contrats Commerciaux
- **Format** : `CONTRACT-[N°]`
- **Template** : En-tête officiel UBI, parties contractantes, clauses détaillées, signatures, sceaux officiels
- **Exemples** : Fourniture de minerais, vente d'armes, accords commerciaux

### 2. Lettres Secrètes
- **Format** : `LETTER-[N°]`
- **Template** : Papier parchemin, écriture manuscrite, cachet de cire, code secret, pli discret
- **Exemples** : Chantage, menaces, révélations, correspondances privées

### 3. Accords Politiques
- **Format** : `TREATY-[N°]`
- **Template** : Parchemin officiel, sceaux des cités, signatures multiples, calligraphie ornée
- **Exemples** : Traités de paix, alliances, accords territoriaux

### 4. Testaments et Successions
- **Format** : `WILL-[N°]`
- **Template** : Document notarié, signatures témoins, sceau officiel, encre noire
- **Exemples** : Testaments nobles, transferts de pouvoir, héritages

### 5. Correspondances Compromettantes
- **Format** : `CORRESP-[N°]`
- **Template** : Lettre personnelle, écriture cursive, taches, plis, parfum
- **Exemples** : Liaisons secrètes, affaires extra-conjugales, révélations privées

### 6. Constitutions et Chartes
- **Format** : `CHARTER-[N°]`
- **Template** : Parchemin majestueux, calligraphie ornée, sceaux multiples, dorures
- **Exemples** : Constitution de la Confédération, chartes fondatrices

### 7. Reçus de Prêts
- **Format** : `LOAN-[N°]`
- **Template** : Document bancaire, tampons officiels, calculs d'intérêts, signatures
- **Exemples** : Prêts personnels, prêts commerciaux, dettes

### 8. Plans Secrets
- **Format** : `PLAN-[N°]`
- **Template** : Schémas, croquis, annotations manuscrites, codes, cartes
- **Exemples** : Plans de coups d'État, infiltrations, opérations secrètes

### 9. Accords de Blanchiment
- **Format** : `LAUNDER-[N°]`
- **Template** : Document codé, signatures anonymes, montants en code
- **Exemples** : Blanchiment d'argent, détournements, opérations illégales

### 10. Contrats de Mariage
- **Format** : `MARRIAGE-[N°]`
- **Template** : Document officiel, signatures des familles, témoins, dot
- **Exemples** : Alliances familiales, mariages politiques, contrats de dot

## Statuts des Documents

### Actif
- **Définition** : Document en vigueur, consultable
- **Accès** : Selon la criticité
- **Exemples** : Contrats en cours, testaments valides

### Archivé
- **Définition** : Document terminé, conservé pour référence
- **Accès** : Archivistes uniquement
- **Exemples** : Contrats expirés, anciens traités

### Classifié
- **Définition** : Document ultra-secret, accès restreint
- **Accès** : Directeur + 1 personne autorisée
- **Exemples** : Plans de coups d'État, preuves de crimes

### Détruit
- **Définition** : Document supprimé, trace dans le registre
- **Accès** : Aucun
- **Exemples** : Documents compromettants brûlés

### Perdu
- **Définition** : Document égaré ou volé
- **Accès** : Recherche en cours
- **Exemples** : Vols, pertes accidentelles

## Règles de Sécurité

### Accès aux Coffres
1. **🔴 Critique** : Directeur + 1 garde de confiance
2. **🟠 Très Sensible** : Conseil de direction + archiviste en chef
3. **🟡 Sensible** : Personnel autorisé + archivistes
4. **🟢 Standard** : Personnel bancaire standard

### Procédures de Consultation
1. Demande écrite avec justification
2. Autorisation selon le niveau de criticité
3. Consultation sous surveillance
4. Signature de non-divulgation

### Procédures de Dépôt
1. Vérification de l'identité du déposant
2. Classification de la criticité
3. Attribution automatique de la zone de coffre selon la criticité
4. Enregistrement dans le registre
5. Stockage sécurisé
