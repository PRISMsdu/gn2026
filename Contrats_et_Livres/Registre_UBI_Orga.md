### Système de Numérotation
- **Références** : code pièce identique au nom de fichier sans `.md`, au format `TT-R-YYY-NNN`.
- **Date de Dépôt** : format `YYY-MM-DD`, où `YYY` est l'année in-univers, `MM` le mois en chiffres romains du calendrier de Krondaar, et `DD` le jour sur deux chiffres. Exemple : `545-IV-21`.
- **Séquence** : les entrées du tableau vivant ci-dessus concernent surtout les trois à cinq dernières années autour de l’an 547 ; le suffixe `NNN` est le rang global dans l’année de dépôt.
- **Références de pièces physiques** : chaque document porte un code pièce unique, identique au nom de fichier sans extension (ex. `CO-II-545-001`, `CP-III-542-001`). Détail du format : `TT-R-YYY-NNN` — `TT` = deux lettres (type ou template, voir grille ci-dessous) ; `R` = criticité en chiffres romains : `I` (standard), `II` (sensible), `III` (très sensible), `IV` (critique) ; `YYY` = année in-univers du dépôt ; `NNN` = numéro séquentiel global dans l’année. Le fichier est `Contrats_et_Livres/TT-R-YYY-NNN.md`. L'unicité du code est garantie par le registre avant toute publication ou antidatation.
- **Grille des deux lettres (`TT`)** : alignée sur les templates et les types d’archives — `CO` contrat commercial (CONTRACT) ; `DE` contrat de dette (DEBT) ; `AL` alliance (ALLIANCE) ; `SE` service (SERVICE) ; `EP` exploitation (EXPLOITATION) ; `EC` exclusivité (EXCLUSIVITY) ; `PR` protection (PROTECTION) ; `MA` mariage (MARRIAGE) ; `CP` correspondance compromettante ; `CC` correspondance commerciale ; `FA` document falsifié ; `RA` rapport d’agent ; `FC` fiche comptable ; `RD` reconnaissance de dette ; `BM` billet maritime ; `FL` fragment de lettre ; `MC` message codé ; `PA` placard anonyme ; `BC` bordereau de caisse ; `MQ` marque de quai ; `AC` avis de conciliation ; `FM` fragment de message ; `TR` tableau de relais ; `NS` note de service ; `GC` grille de contact ; `AN` annexe commerciale.
- **Préfixes spéciaux** (hors schéma `TT-R-YYY-NNN`, usage interne rare) :
  - `UBI-SEC-[N°]` pour les documents ultra-secrets.
  - `UBI-TEMP-[N°]` pour les documents temporaires.

## Criticité : définition et accès

Chaque rang aligne la définition, la nature du risque si la pièce fuit et les personnes habilitées à l’accès. Les codes pièce reprennent la criticité en chiffres romains : `IV` = critique, `III` = très sensible, `II` = sensible, `I` = standard.

### IV — Critique
- **Définition** : documents pouvant causer la chute de gouvernements, révélations de crimes majeurs, génocides ; chantage sur dirigeants suprêmes.
- **Accès** : directeur avec Corvus, archiviste en chef et gardes.
- **Exemples** : constitutions, plans de coups d’État, preuves de génocide ou de crimes majeurs, preuves de chantage sur dirigeants suprêmes.

### III — Très sensible
- **Définition** : scandales politiques majeurs, malversations importantes, chantage sur nobles.
- **Accès** : conseil de direction + archiviste en chef.
- **Exemples** : malversations bancaires, scandales sexuels de nobles, accords secrets entre cités, malversations et dossiers politiques sensibles.

### II — Sensible
- **Définition** : affaires privées compromettantes, correspondances diplomatiques, dettes personnelles importantes.
- **Accès** : personnel autorisé + archivistes.
- **Exemples** : contrats commerciaux sensibles, correspondances diplomatiques, dettes importantes.

### I — Standard
- **Définition** : contrats courants, correspondances publiques, documents administratifs, prêts courants.
- **Accès** : personnel bancaire standard.
- **Exemples** : prêts standards, contrats de mariage publics, testaments normaux, documents administratifs courants.

## Types de Documents et Templates

### 1. Contrats Commerciaux
- **Format** : code pièce `CO-R-YYY-NNN` (fichier `CO-R-YYY-NNN.md`, voir colonne Références du tableau ; autres types de contrat : `DE`, `AL`, `SE`, `EP`, `EC`, `PR`, `MA` selon le template)
- **Template** : en-tête officiel UBI, parties contractantes, clauses détaillées, signatures, sceaux officiels.
- **Exemples** : fourniture de minerais, vente d'armes, accords commerciaux.

### 2. Lettres Secrètes
- **Format** : `LETTER-[N°]`
- **Template** : papier parchemin, écriture manuscrite, cachet de cire, code secret, pli discret.
- **Exemples** : chantage, menaces, révélations, correspondances privées.

### 3. Accords Politiques
- **Format** : `TREATY-[N°]`
- **Template** : parchemin officiel, sceaux des cités, signatures multiples, calligraphie ornée.
- **Exemples** : traités de paix, alliances, accords territoriaux.

### 4. Testaments et Successions
- **Format** : `WILL-[N°]`
- **Template** : document notarié, signatures témoins, sceau officiel, encre noire.
- **Exemples** : testaments nobles, transferts de pouvoir, héritages.

### 5. Correspondances Compromettantes
- **Format** : code pièce `CP-R-YYY-NNN` (fichier `CP-R-YYY-NNN.md`, voir colonne Références du tableau ; correspondance commerciale : `CC`)
- **Template** : lettre personnelle, écriture cursive, taches, plis, parfum.
- **Exemples** : liaisons secrètes, affaires extra-conjugales, révélations privées.

### 6. Constitutions et Chartes
- **Format** : `CHARTER-[N°]`
- **Template** : parchemin majestueux, calligraphie ornée, sceaux multiples, dorures.
- **Exemples** : constitution de la Confédération, chartes fondatrices.

### 7. Reçus de Prêts
- **Format** : `LOAN-[N°]`
- **Template** : document bancaire, tampons officiels, calculs d'intérêts, signatures.
- **Exemples** : prêts personnels, prêts commerciaux, dettes.

### 8. Plans Secrets
- **Format** : `PLAN-[N°]`
- **Template** : schémas, croquis, annotations manuscrites, codes, cartes.
- **Exemples** : plans de coups d'État, infiltrations, opérations secrètes.

### 9. Accords de Blanchiment
- **Format** : `LAUNDER-[N°]`
- **Template** : document codé, signatures anonymes, montants en code.
- **Exemples** : blanchiment d'argent, détournements, opérations illégales.

### 10. Contrats de Mariage
- **Format** : `MARRIAGE-[N°]`
- **Template** : document officiel, signatures des familles, témoins, dot.
- **Exemples** : alliances familiales, mariages politiques, contrats de dot.

## Règles de Sécurité

Les habilitations d’accès par rang de criticité sont récapitulées dans la section « Criticité : définition et accès » ci-dessus.

### Procédures de Consultation
1. Demande écrite avec justification.
2. Autorisation selon le niveau de criticité.
3. Consultation sous surveillance.
4. Signature de non-divulgation.

### Procédures de Dépôt
1. Vérification de l'identité du déposant.
2. Classification de la criticité.
3. Enregistrement du niveau de criticité dans le code pièce.
4. Enregistrement dans le registre.
5. Stockage sécurisé.
